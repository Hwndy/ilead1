# iVintage Public Website Redesign

## Goal
Redesign the complete public website into a modern, content-led experience that feels unmistakably iVintage College while keeping the signed-in application unchanged.

## Design preview first
- Create a bespoke homepage preview using the official iVintage logo, navy, steel blue, lime, white, arch language, and real school content.
- Show the actual Day School, Boarding, Tahfeedh, ICT, admissions, facilities, news, testimonials, gallery, and contact pathways—no invented statistics or university-style content.
- Use a predominantly white canvas, bold navy typography, controlled lime emphasis, authentic school imagery, and a distinctly modern Nigerian Islamic-school character.
- Present desktop and mobile views for review.
- Make no public website changes until the preview is approved.

## After design approval
- Extend the approved visual system across Home, About, Academics, Admissions, Student Life, News, Gallery, Contact, and all public forms.
- Preserve every current route, form, link, editable admin-controlled field, fallback value, and submission workflow.
- Keep navigation and calls to action clear, make long content easy to scan, and ensure each page has a purposeful layout rather than repeating one template.
- Keep the existing Website editor connected so administrators can continue changing public content without code.

## Quality checks
- Verify all public pages and forms on desktop and mobile.
- Check navigation, admissions actions, media, text contrast, overflow, loading states, and admin-managed content fallbacks.
- Confirm no signed-in dashboard styling or behavior changes.
